Temas del Curso

HTML5 Semántico y Estructura

Aprenderemos a utilizar las etiquetas semánticas de HTML5 para crear estructuras web accesibles y bien organizadas. Estudiaremos elementos como header, nav, main, section, article, aside y footer para mejorar la comprensión del código tanto por humanos como por motores de búsqueda.

Videos del tema

Introducción a HTML5 Semántico

Conceptos básicos sobre la importancia de la semántica en el desarrollo web moderno.

Estructura de Documentos HTML5

Cómo organizar correctamente las secciones principales de una página web.

Accesibilidad con HTML5

Mejores prácticas para hacer sitios web accesibles usando etiquetas semánticas.

JavaScript Moderno y DOM

Exploraremos las funcionalidades modernas de JavaScript ES6+ y cómo manipular el Document Object Model (DOM) para crear interfaces interactivas. Cubriremos conceptos como arrow functions, destructuring, y métodos modernos de arrays.

Videos del tema

Manipulación del DOM con JavaScript

Técnicas para seleccionar y modificar elementos del documento dinámicamente.

Eventos y Manejadores en JS

Cómo responder a interacciones del usuario mediante event listeners.

JavaScript Asíncrono

Introducción a Promises, async/await y peticiones fetch.

Diseño Responsive con CSS3

Domina las técnicas de diseño responsive utilizando CSS Grid y Flexbox. Aprenderemos a crear layouts que se adapten a diferentes tamaños de pantalla, implementando media queries y unidades relativas para una experiencia óptima en móviles y tablets.

Videos del tema

Flexbox Fundamentals

Domina las propiedades principales de Flexbox para layouts unidimensionales.

CSS Grid Layout

Creación de diseños bidimensionales complejos con Grid CSS.

Media Queries en Acción

Cómo adaptar tu diseño a diferentes dispositivos y resoluciones.
